# Contributing

Thanks for taking the time to improve Agent Bus.

## Development Setup

```bash
npm install
npm test
```

## Pull Requests

- Keep changes focused and describe the behavior they change.
- Add or update tests for event lifecycle, route handling, or task ledger changes.
- Avoid committing credentials, local user IDs, absolute local paths, or machine-specific configuration.
- Keep public documentation generic enough for other OpenClaw users.

## Security

Please do not open public issues containing secrets, tokens, webhook keys, private session IDs, or sensitive logs. Report sensitive security findings privately to the repository owner.
